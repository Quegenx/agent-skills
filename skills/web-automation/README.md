# Web automation skills

Agents and tests working through a real browser or device: end-to-end tests for web and mobile (`e2e-testing`, including Maestro and Patrol for Flutter and React Native), driving a browser safely (`browser-automation`), getting data from the web (`web-scraping`), exposing a site's actions as agent tools (`webmcp`), and multi-source research reports (`web-research`). Details in the [main README](../../README.md#web-automation).

5 skills.

## Skills

| Skill | Covers |
|---|---|
| [e2e-testing](./e2e-testing/SKILL.md) | End-to-end tests for web and mobile: agentic runners with exact checks, locators that don't flake, debugging, bug bashes and adversarial UI QA, migrating suites, project verification skills, Maestro for React Native, Patrol, Maestro and e2e for Flutter; worst-case data on a component, and Playwright probes of hover, layout and font invariants; viewport sweeps and a page without WebGL; a cookie consent journey proven by network requests |
| [browser-automation](./browser-automation/SKILL.md) | Agents driving a browser: the snapshot and act loop, local versus cloud browsers, signed-in sessions and cookies as credentials, a safe browser with a domain allowlist, recording and diagnosing runs, self-improving task loops and judging, runs turned into scripts, serverless browser functions, migrating to Stagehand; reading how a page or effect was built; a stop rule for blocks on third-party sites. Also: Attached-page selection and version-scoped CDP limitations, evidence before acting and artifact-first run diagnosis; evasion is named only as a do-not. |
| [web-scraping](./web-scraping/SKILL.md) | Data from the web with the lightest tool: fetch, browser or crawler, search without a browser, fetched content as untrusted input, parsing, polite crawling with checkpoints, an MCP scraping server, captured traffic turned into an OpenAPI spec; robots.txt as Google reads it, honest block reports. Also: Indexed corpus evidence, source provenance, explicit partial/inferred status and corpus pagination distinct from source-site pagination. |
| [webmcp](./webmcp/SKILL.md) | A web app's actions as WebMCP tools for agents: from source code or from a live URL, task-level tools, closed schemas, risk classes and confirmations, validation and probing, an audit rubric |
| [web-research](./web-research/SKILL.md) | Company research, competitor analysis and event prospecting with parallel research subagents: call caps, one file per entity, rules against invented facts, confirmation gates, matrices and battle cards from verified evidence, HTML and CSV reports; provenance for person files, facts before the angle |
