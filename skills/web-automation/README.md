# Web automation skills

Agents and tests working through a real browser or device: end-to-end tests for web and mobile (`e2e-testing`, including Maestro and Patrol for Flutter and React Native), driving a browser safely (`browser-automation`), getting data from the web (`web-scraping`), exposing a site's actions as agent tools (`webmcp`), and multi-source research reports (`web-research`). Details in the [main README](../../README.md#web-automation).

5 skills.

## Skills

| Skill | Covers |
|---|---|
| [e2e-testing](./e2e-testing/SKILL.md) | End-to-end web/mobile journeys, agentic runners with exact checks, reliable locators, debugging, bug bashes, suite migration, project verification skills, decision-model execution and network-proven cookie consent. Canonical Maestro and shared mobile-engine setup, Flutter-specific Patrol/e2e examples, worst-case data, adversarial UI QA, hover/layout/font invariants and responsive checks; canvas proof routes to WebGL. |
| [browser-automation](./browser-automation/SKILL.md) | The snapshot/act loop, attached-page ownership, local/cloud browsers, version-scoped CDP and signed-in sessions, credential-safe cookies and scoped interception. Paired-clock tracing, artifact-first diagnosis, task loops/judging, code generation, serverless functions and pinned Stagehand migration. Explanation-only inspection and exact reconstruction route to pixel-reverse-engineer; evasion stays a do-not. |
| [web-scraping](./web-scraping/SKILL.md) | The lightest permitted fetch/browser/crawler, search, untrusted-content handling, parsing, checkpointed crawling and MCP servers. Canonical research extractor/CLI adapters with tagged output variants, qualified Scrapling contracts, Google robots branches, corpus pagination and honest coverage/block reports. Observed-traffic OpenAPI generation routes to reverse-engineering. |
| [webmcp](./webmcp/SKILL.md) | Source-app and injected tools for complete user tasks: closed discovery/runtime schemas, current browser lifecycle separated from pinned drivers/generators, annotations, rejection versus returned failure, execution cancellation, shared consequence gates, validation/probing and an audit rubric. Upstream helpers are explicit prerequisites. |
| [web-research](./web-research/SKILL.md) | Company research, competitor analysis and event prospecting with source-tagged profile/lane conflicts, entity call caps, bounded discovery, one file per entity, evidence fields and person provenance. Explicit paid-gate authorization, run-owned cleanup, verified matrices/battle cards and HTML/CSV reports with source-workspace prerequisites; transport and news definitions route to their owners. |
