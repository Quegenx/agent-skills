# Anti-AI-slop skills

Keep prose, copy, interfaces and code from reading as generic AI output. Start with `anti-slop`, which holds the shared rules and routes to `anti-slop-writing`, `anti-slop-copy`, `anti-slop-ui` and `anti-slop-code`. Details in the [main README](../../README.md#anti-ai-slop).

5 skills.

## Skills

Start with `anti-slop`; it holds the shared rules and routes to the others.

- **[anti-slop](./anti-slop/SKILL.md)**: The shared rules (real over invented, specific over generic) for prose, copy, interfaces, code and the agent's own plans and replies.
- **[anti-slop-writing](./anti-slop-writing/SKILL.md)**: Voice-preserving prose, evidence-based audits, Hebrew guidance and developer docs; documented commands and local assets checked against actual manifests/files.
- **[anti-slop-copy](./anti-slop-copy/SKILL.md)**: Website, marketing and product copy that converts: pages, headlines, CTAs, emails and interface text. Also Intl formatting, destructive-dialog copy and P0 to P3 copy reviews. Also drafting, a seven-sweep review, brand voice, shipped changes turned into announcements, and the shared product context file. Updated coverage: Grounded product copy, point edits, shared context, review panels and source-attributed alternatives. Research-to-copy traceability, scoped headline exploration and truthful early-stage proof handling.
- **[anti-slop-ui](./anti-slop-ui/SKILL.md)**: Purposeful interfaces, product-specific concepts where no owner design applies, honest chart data, component states, responsive/RTL behavior and scoped WCAG contrast. Routes exact reconstruction to pixel-reverse-engineer.
- **[anti-slop-code](./anti-slop-code/SKILL.md)**: Behavior-preserving cleanup, duplication pointers and actual runtime contracts; optional FixMySlop scans, version/coverage limits, baselines and manual false-positive triage. P0 to P3 severity stays separate from pre-existing origin.
