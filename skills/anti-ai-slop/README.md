# Anti-AI-slop skills

Keep prose, copy, interfaces and code from reading as generic AI output. Start with `anti-slop`, which holds the shared rules and routes to `anti-slop-writing`, `anti-slop-copy`, `anti-slop-ui` and `anti-slop-code`. Details in the [main README](../../README.md#anti-ai-slop).

5 skills.

## Skills

Start with `anti-slop`; it holds the shared rules and routes to the others.

- **[anti-slop](./anti-slop/SKILL.md)**: The shared rules (real over invented, specific over generic) for prose, copy, interfaces, code and the agent's own plans and replies.
- **[anti-slop-writing](./anti-slop-writing/SKILL.md)**: Edits prose so it reads like a sharp human wrote it, in the writer's voice, or audits a text and names the AI-writing patterns. Any language, with a Hebrew file. Also developer docs: tutorials, how-tos, reference and framework guides. Also a point-edit mode, second-generation, social and email tells, and a plain-words list. Also source-attributed API wording and self-contained reference slices for agents. Updated coverage: Voice-preserving prose and developer docs, evidence-based audits and Hebrew language guidance.
- **[anti-slop-copy](./anti-slop-copy/SKILL.md)**: Website, marketing and product copy that converts: pages, headlines, CTAs, emails and interface text. Also Intl formatting, destructive-dialog copy and P0 to P3 copy reviews. Also drafting, a seven-sweep review, brand voice, shipped changes turned into announcements, and the shared product context file. Updated coverage: Grounded product copy, point edits, shared context, review panels and source-attributed alternatives.
- **[anti-slop-ui](./anti-slop-ui/SKILL.md)**: Interfaces that don't look template-built and actually work: the purpose test for every visual technique. Also a cross-discipline review on P0 to P3, a page of every component state, side-by-side variants, building from a Figma design, design principles, type review and touch on phones. Updated coverage: Purposeful interfaces, component states, responsive/RTL behavior and correctly scoped WCAG contrast.
- **[anti-slop-code](./anti-slop-code/SKILL.md)**: Removes AI code slop without changing behavior: narrating comments, bloated names, needless wrappers, misplaced error handling. Links to the jscpd duplication reference. Updated coverage: Behavior-preserving code cleanup, duplication pointers and runtime-qualified defensive checks.

The jscpd reference lives in [refactoring/DUPLICATION.md](../architecture/refactoring/DUPLICATION.md).
