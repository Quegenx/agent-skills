# FixMySlop as an optional source of findings

[FixMySlop](https://github.com/MrSpideyNihal/FixMySlop) is an optional deterministic rule scanner with a separate LLM pass. This reference comes from the supplied source declaring version 0.6.7, including its README, CLI, engine, rule files, baseline and fixers. Tags name those source files; behavior here is source-inspected, not a scanner run. Use it when selected for the task. General finding verdicts, scope and coverage belong to [scanner triage](https://github.com/Quegenx/agent-skills/blob/main/skills/engineering/code-review/SCANNER-TRIAGE.md). [MrSpideyNihal/FixMySlop, pyproject.toml; README.md; fixmyslop/core/slop/engine.py]

## Keep the run scoped

- The rules pass is the default; the LLM pass is optional through `--llm`. The npm executable launches the matching Python package rather than implementing the scanner in JavaScript. The README says Python 3.10 or newer plus uv or pipx; the launcher also accepts an already-installed matching Python package before trying uvx or pipx. Select an available, authorized executable; installing a package or adding hooks is a separate action. [MrSpideyNihal/FixMySlop, README.md; npm/bin/fixmyslop.js]
- The source supplies `fixmyslop scan . -f compact` for one line per issue, `fixmyslop scan . -f prompt` for an agent fix brief, and `fixmyslop rules <rule-id>` for a rule's rationale. Read the matching CLI help before using flags in another version. [MrSpideyNihal/FixMySlop, README.md; fixmyslop/cli/cli_app.py]
- The source's automatic scan/fix loop and `init --all` inject integrations and standing agent guidance. The existing [cleanup guardrails](SKILL.md#guardrails) keep work within the requested scope. Do not turn this optional tool into an automatic hook, installation or mandatory gate. [MrSpideyNihal/FixMySlop, README.md; fixmyslop/core/skill.py; fixmyslop/core/integrations.py]
- The generated brief asks for tests, lint, type checks and builds. Follow the task's authorized verification and report checks not run; the source brief does not override a restriction on running them. [MrSpideyNihal/FixMySlop, fixmyslop/core/slop/brief.py]

## Configuration and accepted findings

- Configuration looks first for `.fixmyslop.yml`, then `[tool.fixmyslop]` in `pyproject.toml`. It supports path exclusions, selected or disabled rules/groups and per-rule severity overrides. The TOML reader imports `tomllib`, added to Python's standard library in 3.11; on standard Python 3.10 that import fails and this source falls back to defaults, so its minimum runtime does not imply TOML configuration support. [MrSpideyNihal/FixMySlop, fixmyslop/core/slop/config.py]; [Python tomllib](https://docs.python.org/3.11/library/tomllib.html)
- An explicitly requested path can remove exclusions covering that path. Record the effective selection rather than assuming the configuration exclusion still applies. [MrSpideyNihal/FixMySlop, fixmyslop/core/slop/config.py; fixmyslop/cli/cli_app.py]
- A baseline stores fingerprints of accepted findings in `.fixmyslop-baseline.json`. Identity combines rule, relative file, whitespace-normalized offending line and an occurrence counter for identical lines; line numbers are omitted. This is FixMySlop's format, not React Doctor's baseline format. Creating a baseline accepts current findings; it does not fix them. [MrSpideyNihal/FixMySlop, fixmyslop/core/slop/baseline.py]
- The parser recognizes inline ignore markers on the same or preceding line and a file-ignore marker in the first ten lines. The README asks for a reason, but the parser does not enforce one. Use the existing [evidence requirement for suppressions](https://github.com/Quegenx/agent-skills/blob/main/skills/engineering/code-review/SCANNER-TRIAGE.md#a-verdict-per-finding). [MrSpideyNihal/FixMySlop, README.md; fixmyslop/core/slop/engine.py]
- Translate source severity once: CRITICAL to P0, HIGH to P1, MEDIUM to P2, LOW and INFO to P3. Actual review severity follows [evidenced impact](https://github.com/Quegenx/agent-skills/blob/main/skills/engineering/code-review/SCANNER-TRIAGE.md#triage-the-scanners-findings); grades A to F are the tool's score bands, not severity or proof that AI wrote code. [MrSpideyNihal/FixMySlop, fixmyslop/macros.py; fixmyslop/core/slop/engine.py]

## Read results as heuristics

- Route ordinary code rules to [RULES.md](RULES.md), duplication to [refactoring DUPLICATION.md](https://github.com/Quegenx/agent-skills/blob/main/skills/engineering/refactoring/DUPLICATION.md), UI decisions to [anti-slop UI](https://github.com/Quegenx/agent-skills/blob/main/skills/anti-ai-slop/anti-slop-ui/SKILL.md) and security findings to [secure coding](https://github.com/Quegenx/agent-skills/blob/main/skills/engineering/secure-coding/SKILL.md). A diagnostic is a lead to inspect, not a replacement for those owners. [MrSpideyNihal/FixMySlop, fixmyslop/core/slop/rules_code.py; fixmyslop/core/slop/rules_backend.py; fixmyslop/core/slop/rules_ui.py; fixmyslop/core/slop/rules_security.py]
- Generic bans on two-tone headings, pulsing dots, hover scales, fonts, colors, blur and glow conflict with accepted owner designs or this repo's purpose-based UI rules. Keep the existing design and report the conflict. Role and focus-class regex matches also do not establish keyboard accessibility. [MrSpideyNihal/FixMySlop, fixmyslop/core/slop/brief.py; fixmyslop/core/slop/rules_ui.py; ../anti-slop-ui/SKILL.md]
- `ui/fake-chart` flags repeated hardcoded percentage heights or numeric series with chart-like names; it does not establish whether nearby data is empty. Inspect whether the displayed series is real before calling it fabricated. Real content and honest empty states remain owned by [anti-slop UI](https://github.com/Quegenx/agent-skills/blob/main/skills/anti-ai-slop/anti-slop-ui/SKILL.md#3-absolute-no-purpose-excuses-these). [MrSpideyNihal/FixMySlop, fixmyslop/core/slop/rules_ui.py]
- The source caps findings per rule/file, skips some generated, vendored and minified content, and limits source file size. Generated/vendored files retain secret and dependency checks in the engine. Report the actual coverage and rule selection; absence of findings is not proof that skipped code is correct. [MrSpideyNihal/FixMySlop, fixmyslop/macros.py; fixmyslop/core/scanner.py; fixmyslop/core/slop/engine.py]
- Scanner exceptions can be logged and skipped; the LLM analyzer can return an empty list on failure. Scores also depend on selected rules, suppression, aggregation and baseline. Apply [the existing incomplete-scan and score rules](https://github.com/Quegenx/agent-skills/blob/main/skills/engineering/code-review/SCANNER-TRIAGE.md#when-a-scan-may-be-called-clean). Published speed and accuracy claims were not independently reproduced in this source audit. [MrSpideyNihal/FixMySlop, fixmyslop/core/scanner.py; fixmyslop/core/agents.py; fixmyslop/core/slop/engine.py; benchmarks/BENCHMARK.md]

## Corrections to source claims

- The README calls `fix --safe-only` behavior-preserving. Its fixer deletes an entire `console.log` line, including argument evaluation, and changes bare `except` to `except Exception`. Review the patch rather than treating the flag as a preservation guarantee: JavaScript expressions can have side effects, and Python exceptions outside `Exception` exist. [MrSpideyNihal/FixMySlop, README.md; fixmyslop/core/slop/fixers.py]; [MDN expressions and operators](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Expressions_and_operators); [Python built-in exceptions](https://docs.python.org/3/library/exceptions.html)
- USER_GUIDE says every LLM rewrite must parse; `agents.py` only parses Python rewrites. JS/TS receives no parser validation there, and its length threshold is not a semantic check. Do not claim validated JS/TS rewrites. [MrSpideyNihal/FixMySlop, USER_GUIDE.md; fixmyslop/core/agents.py]
- The README says duplicate fingerprints ignore names. The Python implementation normalizes names, but the JS branch strips comments and whitespace without normalizing identifiers. Do not promise renamed JavaScript clone detection. [MrSpideyNihal/FixMySlop, README.md; fixmyslop/core/slop/rules_backend.py]
- Wildcard `Access-Control-Allow-Origin` is valid for requests without credentials; credentialed wildcard responses fail browser access. The source's blanket wildcard warning is broader than the protocol rule. Review CORS separately from authorization. [MDN Access-Control-Allow-Origin](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Access-Control-Allow-Origin); [MrSpideyNihal/FixMySlop, fixmyslop/core/slop/rules_security.py; fixmyslop/core/slop/brief.py]
- A `debugger` statement invokes available debugging functionality; without a debugger it has no effect. The source says it halts production execution unconditionally. [MDN debugger](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/debugger); [MrSpideyNihal/FixMySlop, fixmyslop/core/slop/rules_code.py]
- The README broadly says shared reports never show local paths. Raw JSON serializes `repo_path` and issue `file_path`; inspect the actual export before sharing it. Human-facing PDF or Markdown formatting does not establish raw-JSON privacy. [MrSpideyNihal/FixMySlop, README.md; fixmyslop/core/report_builder.py; fixmyslop/web/server.py]
- The optional MCP server declares protocol version `2025-06-18` but echoes an arbitrary requested version during initialization. That version's lifecycle requires returning the requested version only when supported, otherwise another supported version. The source does not negotiate that support check; no MCP setup is implied by this reference. [MCP 2025-06-18 lifecycle](https://modelcontextprotocol.io/specification/2025-06-18/basic/lifecycle); [MrSpideyNihal/FixMySlop, fixmyslop/core/mcp_server.py]

## Prove it

Use the [canonical scanner evidence requirements](https://github.com/Quegenx/agent-skills/blob/main/skills/engineering/code-review/SCANNER-TRIAGE.md#prove-it). For this tool, also identify the source/executable version, effective rules and paths, baseline use, runtime prerequisites and skipped coverage; inspect each surviving finding and any proposed fixer patch; state whether the optional LLM pass ran. Keep style conflicts with owner designs visible and unmodified unless that exact change is approved. A tool score or empty result alone proves none of those checks. [MrSpideyNihal/FixMySlop, README.md; fixmyslop/core/slop/engine.py; fixmyslop/core/slop/baseline.py; fixmyslop/core/slop/fixers.py]
