# Turn interface references into builder prompts

Extract a web or app's layout and interaction contract from inspected HTML, a live page or a reference video. Sources: [MengTo/Skills, video-to-superprompt/SKILL.md and references/superprompt-template.md; html-to-interaction-prompts/SKILL.md; daily-ui-inspiration-capture/SKILL.md; design-first-ui-prompting/SKILL.md; build-daily-inspiration-sites/SKILL.md]. This is an optional research and handoff branch; it does not replace an accepted owner design.

## Establish the evidence boundary

- State whether the task asks for exact recreation, inspired adaptation, a prompt pack or implementation. Locate the actual source and report missing access. For exact recreation, inspect available source HTML/CSS/JS as well as the recording. [MengTo/Skills, video-to-superprompt/SKILL.md, Workflow]
- Treat the reference's title, live page URL and cover-image URL as different records. A marketplace cover is not proof of a working interaction. Prefer captured material from the original brief when a later live version has drifted. Use [REFERENCE-ORIGINALITY.md](REFERENCE-ORIGINALITY.md) when overlap itself is being audited. [MengTo/Skills, html-to-interaction-prompts/SKILL.md, Daily UI Inspiration Capture Contract; audit-reference-originality/SKILL.md, Build the source registry]
- Inspect moving media at representative beats, including opening, transitions and later states. Preserve sequence, pacing and notable behavior. Separate behavior actually observed from an implementation recommendation inferred from appearance; imports and context creation can establish the actual renderer when source exists. [MengTo/Skills, video-to-superprompt/SKILL.md, Inspect the video technically; Analyze in layers; web-technique-to-skill/SKILL.md, Name the demo and disclose the stack]
- Capture stills, real page scrolling and representative motion frames through [browser-automation VISUAL-CAPTURES.md](https://github.com/Quegenx/agent-skills/blob/main/skills/web-automation/browser-automation/VISUAL-CAPTURES.md). Do not present an animated still as live interaction evidence. [MengTo/Skills, html-to-interaction-prompts/SKILL.md, Capture videos when requested]

## Write the prompt as a build contract

- Lead with the thing to build, its audience/purpose and the reference boundary. Include an asset map with verified URLs/local paths or explicit placeholders, brand/content, global design system, motion system, responsive behavior, accessibility, performance and failure conditions. Separate image/video asset-generation prompts from the interface prompt. [MengTo/Skills, video-to-superprompt/SKILL.md; references/superprompt-template.md]
- Describe each actual section in order: purpose, layout anatomy, typography/surfaces/media, initial and settled states, trigger, duration/easing/stagger when known, interaction states, scroll handoff, recommended implementation path and reduced-motion behavior. Include navigation, footer and mobile behavior; do not invent absent proof, pricing, FAQ or testimonials to satisfy a template. [MengTo/Skills, html-to-interaction-prompts/SKILL.md, Write reusable prompts; repository factual-content boundary]
- For a single reusable interaction, the source's compact structure is core idea, technology, implementation, interaction and success. Split by independent interaction idea; keep coupled behaviors together. For inspiration, keep colors, sizing and density adaptive. Exact observed values belong to an authorized reconstruction or are labeled reference presets. [MengTo/Skills, html-to-interaction-prompts/SKILL.md, Decide the prompt list; Write reusable prompts; Prompt Style Rules]
- Let the existing stack win. Name a library only when it changes the implementation choice; simple CSS/sticky/native scrolling does not automatically require a timeline library, smooth-scroll dependency or WebGL renderer. Use actual domain-owner guidance for the selected API. [MengTo/Skills, html-to-interaction-prompts/SKILL.md, Library Guidance]
- For a design-first brief, settle goal, audience, output, wireframe, type/material direction, exact copy and constraints before polishing. Iterate a named variable rather than rewriting the entire brief after every result. The source's fixed model recommendations and universal purple/icon bans are not adopted. [MengTo/Skills, design-first-ui-prompting/SKILL.md and ARTICLE.md; existing anti-slop-ui direction rules]

## Package an optional recurring collection

- Read the project's runbook and recent bundles before choosing a format. Deduplicate normalized title, source URL and image URL against earlier manifests. Keep sources, creator/date when known, capture type, actual page URL, viewport, media paths, pattern notes and the prompt together. [MengTo/Skills, daily-ui-inspiration-capture/SKILL.md, Start; Selection; Manifest Shape]
- The source's dated article preset uses five references, a representative still and local video or explained fallback per item, one full-page image with section crops for each live site, and at least four progression frames after a successful video capture. Its two-second settling wait, exact article headings and file layout are project conventions, not global requirements for reference research. [MengTo/Skills, daily-ui-inspiration-capture/SKILL.md, Output Contract; Capture; Article Shape; Verification]
- If a live-site deliverable is mandatory, replace blocked candidates or report the gap. The HTML source both permits fallback videos and later demands no fallback language for live items; retain honest capture labels rather than erasing the limitation. [MengTo/Skills, html-to-interaction-prompts/SKILL.md, Daily UI Inspiration Capture Contract; Verify]
- For explicitly requested parallel implementations, use isolated workspaces and one concrete reference brief per task. Keep reference grammar distinct from the new product's verified content. The build-daily-sites source suggests inventing metrics/testimonials; use verified facts or explicit placeholders instead. Creating tasks, publishing sites and changing hosting still require the applicable task and host authority. [MengTo/Skills, build-daily-inspiration-sites/SKILL.md]

## Prove it

The prompt covers inspected sections and states, preserves the selected recreation/adaptation boundary, distinguishes observation from recommendations, resolves or labels assets, and includes touch/keyboard/reduced-motion behavior. Reference media comes from the recorded URL/method, crops trace to their full image, duplicates and unavailable evidence are reported, and no fabricated business proof or unrequested publication is implied. [MengTo/Skills, video-to-superprompt/SKILL.md, Verify before finalizing; html-to-interaction-prompts/SKILL.md, Verify; daily-ui-inspiration-capture/SKILL.md, Verification]
