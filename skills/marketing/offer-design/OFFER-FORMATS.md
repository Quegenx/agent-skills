## Service or freelance

[coreyhaines31/marketingskills, offers]

| Component | Default |
|---|---|
| Core | A scoped engagement with a specific deliverable and timeline |
| Bonuses | Templates, frameworks, post-engagement support, tool stack |
| Guarantee | First-milestone gate (paid pilot or first-deliverable refund) |
| Scarcity | Capacity-based (next slot opens [date]) |
| Name | Methodology-named or outcome-named ("The 30-Day Activation Sprint") |
| Price | Project-based with down payment, or monthly retainer |

- **Naming matters disproportionately:** unnamed services compete on price, named ones on positioning.
- **Scope creep kills the offer:** write in, out and optional before the engagement starts.
- **Productize it:** from "I sell consulting" to "I sell the 8-Week Marketing Reset": a name, fixed scope and timeline, fixed price, the same bonuses every time, a defined gate (week-4 check-in, paid pilot, milestone review).

## Course

[coreyhaines31/marketingskills, offers] Async, cohort-based or live.

| Component | Default |
|---|---|
| Core | The curriculum + delivery format |
| Bonuses | Templates, swipe files, case studies, community access |
| Guarantee | Conditional money-back (completion-gated) |
| Scarcity | Cohort scarcity (enrollment closes [date]) |
| Name | Outcome-named or methodology-named |
| Price | Pay in full or 2-4 installments (show the total) |

| Decision | Async | Cohort |
|---|---|---|
| Scarcity | Bonus expiry, price increases | Cohort start date |
| Guarantee | Generous unconditional | Conditional on completion |
| Conversion mechanic | Email funnel, evergreen webinar | Launch window + cohort deadline |
| Default bonus | Templates, swipes | Slack + office hours + 1:1 review |

- **Completion is the marketing asset:** engineer the first win in week 1.
- **Cohort scarcity must be real:** "doors close Friday" followed by "doors reopen Monday" gets noticed.

## Coaching

[coreyhaines31/marketingskills, offers] 1:1, group or mastermind.

| Component | Default |
|---|---|
| Core | Sessions + async access + a specific outcome focus |
| Bonuses | Resources from your library, intros to your network, post-engagement check-ins |
| Guarantee | Outcome-or-extension, or a first-two-sessions off-ramp (a pro-rated refund, not money-back) |
| Scarcity | Capacity-based (N spots per quarter) |
| Name | Identity-named or outcome-named ("Founder Marketing Mastermind") |
| Price | Monthly retainer or a 3, 6 or 12-month engagement |

| Decision | 1:1 | Group / mastermind |
|---|---|---|
| Scarcity | Capacity (4-10 1:1 clients) | Cohort size (8-30 members) |
| Guarantee | First-two-sessions out | Trial period, no refunds after |
| Bonuses | Custom resources, intros | Group access, peer accountability, library access |
| Default delivery | Weekly or biweekly sessions | Monthly group calls + community |

- **Identity is the offer** in a group: name the room, not the coach. **Renewal is the real conversion event:** design for the 6-month decision.

## Info product

[coreyhaines31/marketingskills, offers] Guide, swipe file, template pack, community.

| Component | Default |
|---|---|
| Core | The asset(s) + lifetime access |
| Bonuses | Adjacent assets, walkthroughs, templates |
| Guarantee | Generous unconditional (30-day no-questions) |
| Scarcity | Bonus expiry, price-increase scheduling |
| Name | Outcome-named, often punchy and specific |
| Price | Pay in full |

- **The first five minutes decide engagement;** pair the asset with a 10-minute "do this first" walkthrough.
- **Say what "lifetime" means** (yours, the product's, until you sunset it). Lifetime access isn't a warranty, but the FTC guide's rule for "lifetime" guarantees, name the life, is the right model ([FTC-PRICING-CLAIMS.md](FTC-PRICING-CLAIMS.md#guarantees)).

## High-ticket B2B

[coreyhaines31/marketingskills, offers] $5K+ ACV, sales-led.

| Component | Default |
|---|---|
| Core | A multi-month engagement or annual contract |
| Bonuses | Onboarding, training, integration, dedicated CSM |
| Guarantee | SLA, performance-based, or pilot-gated |
| Scarcity | Quarter-end pricing, capacity (N onboardings per quarter), tier limits |
| Name | Internal-stable ("Enterprise Plan") + a named engagement type ("Strategic Onboarding") |
| Price | Annual contract with quarterly payment, often custom |

- **A buying committee, not a buyer:** the offer lands with the champion, the economic buyer and the influencer at once. **Procurement is the offer:** payment terms, NET 60, security review and MSA are part of it. **Pilots convert sophisticated buyers:** "30-day paid pilot, decide to continue at end". Sales collateral is in [sales-enablement SKILL.md](https://github.com/Quegenx/agent-skills/blob/main/skills/marketing/sales-enablement/SKILL.md).

## Agency retainer

[coreyhaines31/marketingskills, offers]

| Component | Default |
|---|---|
| Core | Monthly deliverables + dedicated team + reporting cadence |
| Bonuses | Strategy sessions, tool access, audit credits, library access |
| Guarantee | Month-1 paid pilot or 90-day out clause |
| Scarcity | Capacity (N clients per vertical per quarter) |
| Name | Tier-named ("Growth", "Scale", "Enterprise") + service line |
| Price | Monthly retainer with a discount for annual commit |

- **Onboarding velocity is the offer** (deliver something in week 1); **reporting is part of the offer**; **tier upgrades are the easiest revenue** when each step up is clear.

## Self-serve SaaS

[coreyhaines31/marketingskills, offers]

| Component | Default |
|---|---|
| Core | Tiered subscription with clear feature differentiation |
| Bonuses | Free onboarding, templates, integrations, partner discounts |
| Guarantee | Free trial, or annual with a 30-day refund |
| Scarcity | Founding pricing for the first N customers, or seasonal launches |
| Name | Tier-named ("Starter", "Pro", "Team", "Enterprise") |
| Price | Monthly or annual with a discount, value-metric-based |

- **Packaging and the value metric do more work here** than guarantees and bonuses: read [pricing-strategy SKILL.md](https://github.com/Quegenx/agent-skills/blob/main/skills/marketing/pricing-strategy/SKILL.md) first. **Free trial design is offer design:** length, gated features, card required or not, automatic conversion ([onboarding-and-upgrades ACTIVATION-MODELS.md](https://github.com/Quegenx/agent-skills/blob/main/skills/marketing/onboarding-and-upgrades/ACTIVATION-MODELS.md)). **The annual plan is an offer lever.** Discounts follow [DISCOUNTS.md](DISCOUNTS.md).

## Direct response

[coreyhaines31/marketingskills, offers] A sales page or video sales letter to cold paid traffic.

| Component | Default |
|---|---|
| Core | The "thing" + a clear payoff |
| Bonuses | Heavy stack (5-7 bonuses) with values that meet 16 CFR 233.2 |
| Guarantee | Aggressive risk reversal (better-than-money-back, double guarantee) that you can perform (16 CFR 239.5) |
| Scarcity | Real time-bound (launch window, evergreen with a hard close) |
| Name | Hooky, often pattern-interrupt |
| Price | Often a single payment with a payment plan offered |

- **Direct-response buyers expect aggression,** and the source calls the format high-skill: bring in someone from that background. The legal edges are sharpest here ([FTC-PRICING-CLAIMS.md](FTC-PRICING-CLAIMS.md)).

## Choosing

[coreyhaines31/marketingskills, offers] Pick the closest match and adapt; the biggest mistake is borrowing a format from a different business type (direct-response bonus stacking on a premium B2B service). Two questions: who buys it and how sophisticated are they; and what is the dominant constraint (services are capacity-bound, SaaS tier-bound, courses cohort- or season-bound)? Match the scarcity format to the real constraint.

## Prove it

The format chosen matches the business type and buyer sophistication; each of its six component defaults is either used or deliberately replaced; and the scarcity named is the business's real constraint.
