# Ad copy formulas

[coreyhaines31/marketingskills, ads, ad-copy-templates.md] Skeletons for primary text; every proof slot takes a real number or a named quote from the product context ([anti-slop-copy SKILL.md](https://github.com/Quegenx/agent-skills/blob/main/skills/anti-ai-slop/anti-slop-copy/SKILL.md#3-tests-every-headline-and-claim-must-pass)), and the source's sample stats are left out.

## Primary text

| Formula | Lines |
|---|---|
| Problem-Agitate-Solve (PAS) | Problem statement / Agitate the pain / Introduce solution / CTA |
| Before-After-Bridge (BAB) | Current painful state / Desired future state / Your product as the bridge |
| Social Proof Lead | Impressive stat or testimonial / What you do / CTA |
| Feature-Benefit Bridge | Feature / So that... / Which means... |
| Direct Response | Bold claim or outcome / Proof point / CTA "with urgency if genuine" |

## Headlines, hooks, CTAs and testing

[coreyhaines31/marketingskills, ads, ad-copy-templates.md]

- **Search headlines:** [Keyword] + [Benefit], [Action] + [Outcome], [Question], [Number] + [Benefit], [Keyword] + [Differentiator], [Price/Offer] + [Keyword].
- **Social hooks:** outcome, curiosity, contrarian, specificity, question, number, story. The source's question hook ("What if you could cut your admin time in half?") is a shape [anti-slop-copy PAGES.md](https://github.com/Quegenx/agent-skills/blob/main/skills/anti-ai-slop/anti-slop-copy/PAGES.md#the-hero-problem-picture-path) keeps out of headlines. The hook slop to avoid is in [anti-slop-copy SKILL.md](https://github.com/Quegenx/agent-skills/blob/main/skills/anti-ai-slop/anti-slop-copy/SKILL.md#5-copy-slop-specific-to-pages).
- **CTAs by stage:** soft for "Top of funnel, cold audiences, complex products" (See How It Works, Watch Demo, Get the Guide); hard for "Bottom of funnel, warm audiences, clear offers" (Start Free Trial, Book a Demo); urgency "use when genuine" only (Offer Ends [Date]); action-oriented (Get Your Free Report, Calculate Your ROI). Write them in sentence case ([anti-slop-copy MICROCOPY.md](https://github.com/Quegenx/agent-skills/blob/main/skills/anti-ai-slop/anti-slop-copy/MICROCOPY.md#rules)).
- **Testing order** "in order of impact": hook or angle, headline, primary benefit, CTA, supporting proof points. "Test one element at a time for clean data." Campaign-side testing is in [paid-ads](https://github.com/Quegenx/agent-skills/blob/main/skills/marketing/paid-ads/SKILL.md); concepts and hooks for creative are in [ad-creative](SKILL.md).

## Prove it

[coreyhaines31/marketingskills, ads, ad-copy-templates.md]

- Every proof slot uses a real number or named quote from the product context.
- Urgency is genuine, CTAs use sentence case, and the page-headline conflict stays explicit.
- Each test changes one element; the testing order starts with the hook or angle.
