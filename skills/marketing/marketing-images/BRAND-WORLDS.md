# Develop a family of reference-inspired campaign worlds

An optional art-direction method from [MengTo/Skills, generate-reference-inspired-brand-worlds/SKILL.md and references/example-prompts.md]. Extract high-level relationships while giving each concept its own meaning, subject and composition. Existing [image rules](SKILL.md#the-rules) and [prompting constraints](PROMPTING.md#the-prompt) remain in force.

## Separate reference grammar from identity

- Inspect every supplied image. Label the primary visual-language reference separately from a current concept used for revision. A style guide is not automatically an edit target whose pixels must remain. Keep reference images out of reusable assets unless redistribution is authorized. [MengTo/Skills, generate-reference-inspired-brand-worlds/SKILL.md, Start correctly]
- Extract density/depth, palette relationships, medium/texture, lighting, emotional temperature, type scale/placement and the role of human presence. Separately list signature people/poses, motif arrangements, distinctive negative space, marks, slogans and letterforms to avoid reproducing. [MengTo/Skills, generate-reference-inspired-brand-worlds/SKILL.md, Extract visual DNA]
- The source uses a subjective similarity dial: 30% distant principles, 50% recognizable influence, 70% an adjacent visual family, and 85% a close art-direction neighbor. These numbers communicate intent; they are not measured similarity, an originality threshold or legal clearance. Its request to change at least four signature elements is a creative checklist, not a safe harbor. [MengTo/Skills, generate-reference-inspired-brand-worlds/SKILL.md, Set the similarity dial; Validate every output]

## Hold the family together and vary the story

- The source proposes four to six shared constants, selected from aspect ratio, medium/texture, palette relationship, wordmark scale/placement, density and emotional tone. Keep those explicit rather than making unrelated styles or only swapping colors. [MengTo/Skills, generate-reference-inspired-brand-worlds/SKILL.md, Build a distinct-brand matrix]
- Give every concept a distinct name, meaning, environment, human ritual and signature motif. Use only the task's authorized fictional or actual identity; do not copy real-brand sample data from a reference. [MengTo/Skills, generate-reference-inspired-brand-worlds/SKILL.md, Build a distinct-brand matrix; repository identity boundary]
- Keep one prompt per distinct concept, naming reference roles, purpose, meaning, scene, subject/action, medium, framing, palette relationships and exclusions. The source's long prompt spine is a briefing structure; it does not override the existing 40-to-80-word generation-prompt default. [MengTo/Skills, generate-reference-inspired-brand-worlds/SKILL.md, Write one prompt per brand; existing PROMPTING.md, The prompt]

## Preserve the selected concept when revising

- For a closer revision, keep the original reference and current concept distinct. Preserve the current name and meaning; change only the intended visual grammar and restate signature exclusions. Save a versioned sibling so the earlier option remains available. [MengTo/Skills, generate-reference-inspired-brand-worlds/SKILL.md, Revise without losing the concept]
- Inspect family resemblance, visible meaning, differences in subject/ritual/motif/composition, aspect ratio, resolution and unwanted text/marks. Make one targeted revision for a failed criterion before changing the entire concept. [MengTo/Skills, generate-reference-inspired-brand-worlds/SKILL.md, Validate every output]

## Conflicting wordmark method

The current image rules put logos and exact text in post. This source instead requests an exact generated wordmark once inside each image and judges its spelling. Keep the identity, spelling and placement as the art-direction contract, but retain post-production rendering of the mark; the source alternative does not authorize generated logos. [coreyhaines31/marketingskills, image, SKILL.md; MengTo/Skills, generate-reference-inspired-brand-worlds/SKILL.md, Write one prompt per brand; Validate every output]

## Prove it

The reference roles, shared constants and per-concept differences are explicit; signature exclusions were inspected; subjective dial values are not presented as measurements; versions and exact prompts are preserved; and the existing logo/text and prompt-length defaults remain intact. Report actual visual inspection and any unverified output. [MengTo/Skills, generate-reference-inspired-brand-worlds/SKILL.md, Validate every output; Save and hand off]
