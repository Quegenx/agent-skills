# Mobile skills

Mobile apps from code to store: `flutter` and `dart` (from the official Flutter and Dart docs and team skills), `app-store-connect` and `google-play` (shipping, review and policy), `aso` (store listings), `app-growth` (ads, attribution, retention), `flutter-ux` (community UX tips from FlutterPro and ApparenceKit, with a design review) and `flutter-render-objects` (custom RenderObjects from renderobjects.com). Several skills draw on third-party skill sets, tagged where used, with the official docs as the authority. Details in the [main README](../../README.md#mobile).
