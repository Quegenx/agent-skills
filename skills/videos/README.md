# Video skills

Make videos with a coding agent, where every frame is code. Start with `make-video`; run `video-setup` once per machine; ask `video-help` which skill fits. The flow and every skill are described in the [main README](../../README.md#videos).

11 skills. The HTML `seek(t)` engine remains the default; use the framework references when the brief requires them.
