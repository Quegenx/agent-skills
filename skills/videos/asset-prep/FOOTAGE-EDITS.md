# Editing supplied footage locally

Use when the job changes existing footage rather than drawing a new film. This guide extracts workflows from [kajisho5/ffmpeg-skill](https://github.com/kajisho5/ffmpeg-skill), especially `scripts/cut.py`, `join.py`, `caption.py`, `overlay.py`, `render.py` and `_common/timeline.py`. It does not bundle that toolkit. Use the installed editor's actual interface; read [MEDIA-INSPECTION.md](MEDIA-INSPECTION.md) before choosing transformations.

## Make the cut's timing explicit

- Distinguish the requested range from actual start, end, duration and delta. Record copy versus re-encode and its reason, and distinguish packet, sample, codec-frame and video-frame precision instead of calling every cut exact. Source defaults and measured tolerances belong to that toolkit, not to every FFmpeg build. [kajisho5/ffmpeg-skill, scripts/cut.py; tests/test_cut_copy.py]
- With input `-ss`, FFmpeg seeks to an earlier seek point where exact seeking is unavailable. Default accurate transcoding decodes/discards the extra segment; stream copy preserves it. The source's MP4 edit-list workflow can hide stored pre-roll from players that honor it, so decode the requested boundaries and disclose stored versus presented material rather than promising identical behavior in every player/editor. [https://ffmpeg.org/ffmpeg.html#Main-options; kajisho5/ffmpeg-skill, references/gotchas.md#keyframe-cuts]
- Keep source time and output time separate after cuts, speed changes, holds and inserted material. Preserve kept/removed ranges, and check boundaries against the original. Check that the reported map matches the resulting selection. [kajisho5/ffmpeg-skill, scripts/silence.py; scripts/freeze.py; tests/test_editing.py]
- Speech boundaries and the repository's 30 ms cut fades remain in [asset-prep's footage rules](SKILL.md#real-use-as-footage). Source `cut.py` uses 20 ms by default; that source policy does not replace the existing 30 ms workflow. [kajisho5/ffmpeg-skill, scripts/cut.py; existing asset-prep, SKILL.md]

## Assemble without silently changing the edit

- Preflight all segments before expensive stages. Name every missing, unreadable, empty or unsuitable input together. If skipping is authorized, report original input indices, skipped items and resulting output placements. Missing audio, intentionally absent audio and a present but threshold-quiet track are separate states. [kajisho5/ffmpeg-skill, scripts/join.py; scripts/render.py; tests/test_orchestration.py]
- Stream-copy concatenation requires compatible streams: the official concat demuxer requires the same streams, codecs and time base. Different stream lengths or inaccurate file durations can introduce gaps/artifacts. The old asset-prep line said to extract and join segments with lossless copy unconditionally; use it only when those requirements and actual boundary checks hold. [https://ffmpeg.org/ffmpeg-formats.html#concat]
- Count transition overlap in expected duration, and keep each segment's sound with its picture. The source crossfade overlaps neighboring clips by the transition duration; verify individual stream spans and sound alignment at joins rather than using container duration alone. [kajisho5/ffmpeg-skill, scripts/join.py; scripts/_common/timeline.py; https://ffmpeg.org/ffmpeg-all.html#acrossfade]

## Preserve captions and supplied layers

- Choose burned pixels versus a toggleable subtitle track explicitly. Report the track and container path actually used; the source toolkit's mux restrictions are not universal subtitle-format limitations. Preserve authored sidecars and name any changed timing, split/dropped cues or text changes. Compare against the original user text, not only an agent-generated intermediate labeled unchanged. [kajisho5/ffmpeg-skill, scripts/caption.py; tests/test_picture.py]
- Fit text against the final displayed frame and actual rendering column. Keep manual breaks and whole emoji clusters; inspect every intended cue for visibility, shaping, clipping and timing. A glyph-coverage listing, ink count or approximate font-width table does not prove readable, correctly shaped captions. [kajisho5/ffmpeg-skill, scripts/_common/wrap.py; scripts/caption.py; tests/test_picture.py]
- For transcription, record the actual engine/model, detected versus assumed language, routing and available word times. Distinguish a missing engine, engine failure, legitimate no speech and missing word timings; filler removal requires measured word start/end pairs. Disclose required first-run model downloads without treating local transcription as a promise of offline setup. [kajisho5/ffmpeg-skill, scripts/_common/asr.py; scripts/silence.py; tests/test_asr.py]
- The source claims drawtext never uses HarfBuzz. Official drawtext requires libfreetype and libharfbuzz, with libfribidi enabling its text-shaping option; retain libass as the source's preferred route, not a universal drawtext impossibility. [https://ffmpeg.org/ffmpeg-all.html#drawtext; kajisho5/ffmpeg-skill, references/gotchas.md#fonts-by-script]
- Place supplied still/video/text layers using explicit destination windows and separate source offsets. Choose the main audio deliberately; a video layer does not imply mixing its sound. Use waveforms, spectra or audiogram plates only when the requested format needs them, with the selected audio track driving both analysis and output. [kajisho5/ffmpeg-skill, scripts/overlay.py; scripts/waveform.py; tests/test_audio.py]
- Energy, duration and sampled motion rank candidates, not meaning. Watch proposed highlights before choosing them; proposed chapter positions do not supply real titles, and the source deliberately labels its titles as placeholders. [kajisho5/ffmpeg-skill, scripts/scenes.py; scripts/metadata.py]

## Replay and editor handoff

- Bind plans to inspected inputs, including cue/LUT/project side files; revalidate before replay. Validate unknown keys and actual output paths before work, protect source aliases and existing authored files, stage replacements and clean failed partial outputs. A dry run may still perform documented measurements: report planned, measured and written work separately. [kajisho5/ffmpeg-skill, scripts/_common/runner.py; scripts/_common/emit.py; scripts/render.py; tests/test_contract.py]
- Cache identity must cover effective options, source identity, output container and relevant tool/build versions. Report reuse and actual fallback rather than treating file existence as proof of a current result; [inspection](MEDIA-INSPECTION.md#keep-evidence-within-its-measured-scope) distinguishes partial from complete fingerprints. [kajisho5/ffmpeg-skill, scripts/render.py; scripts/batch.py; tests/test_orchestration.py]
- Editor timelines translate decisions already made. List every operation not exported, including captions, overlays, crop/fit, audio processing, loudness or delivery settings as applicable to the selected path. A parsed XML/JSON/EDL file is not a successful import in the target editor; report any unperformed roundtrip. [kajisho5/ffmpeg-skill, scripts/_common/timeline.py; docs/contract.md; tests/test_orchestration.py]
- Use [sound-pass](https://github.com/Quegenx/agent-skills/blob/main/skills/videos/sound-pass/SKILL.md#supplied-footage-audio) for audio alignment, quiet detection and bed/master distinctions, and [frame-review](https://github.com/Quegenx/agent-skills/blob/main/skills/videos/frame-review/DELIVERY-CHECKS.md#evidence-limits) for final evidence. [kajisho5/ffmpeg-skill, scripts/sync.py; scripts/audio.py; scripts/_common/emit.py]

## Prove it

Originals and authored sidecars remain protected; requested versus actual timing, changed/dropped streams, caption fidelity, join boundaries, replay/cache identity and editor omissions are reported. Selected checks ran on the delivered artifact; missing measurements and unavailable visual/listening/editor review remain explicit. [kajisho5/ffmpeg-skill, tests/test_cut_copy.py; tests/test_editing.py; tests/test_picture.py; tests/test_orchestration.py]
