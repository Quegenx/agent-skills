# Frontend skills

How UI is built and behaves: the app itself (`app-ui`), the marketing site (`landing-page-ui`), animation and motion in general (`ui-animation`), and SVG drawing, effects and animation (`svg`). The agent's chat UI is in the ai-agents set (`agent-chat-ui`). `app-ui`, `landing-page-ui` and `agent-chat-ui` ship their production source in `reference/`. Details in the [main README](../../README.md#frontend).
