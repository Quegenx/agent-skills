# Frontend skills

How UI is built and behaves: the app itself (`app-ui`), the marketing site (`landing-page-ui`), animation and motion in general (`ui-animation`), SVG drawing, effects and animation (`svg`), modern CSS from nerdy.dev with current browser support (`modern-css`), GSAP (`gsap`), web accessibility (`web-accessibility`), color systems (`color-system`), the Sonner toast library (`sonner`), technical drawings (`technical-drawing`), React with Next.js and React Native (`react`) WebGL on live pages (`webgl`) and cookie consent (`cookie-consent`). The agent's chat UI is in the ai-agents set (`agent-chat-ui`). `app-ui`, `landing-page-ui` and `agent-chat-ui` ship their production source in `reference/`. Details in the [main README](../../README.md#frontend).
